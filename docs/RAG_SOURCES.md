# Curated copilot references

Phase 9 uses three small reviewed passages from two primary public sources. The corpus is local JSON; no embeddings, ChromaDB, runtime web search or external retrieval service is required. Retrieval uses deterministic lowercase word overlap with stable source-ID tie breaking. Every response preserves source attribution, public URL, section, access date, reuse terms and the SHA-256 of the exact local UTF-8 passage.

The catalog is [llm/knowledge/sources.json](../llm/knowledge/sources.json). Each passage is a **curated paraphrase**, not a verbatim quotation or a newly inferred fact about a particular well. Adaptations were made by OilWell AI on 2026-11-10. No images, third-party figures, operational procedures or event-specific fault signatures are copied. These references do not endorse this project or validate its rejected diagnostic detector.

All pages and licensing statements were inspected on **2026-11-10**. The Nature page initially redirected to an inaccessible cookie authorization page; the content and explicit article license were then retrieved successfully using the public article's `error=cookies_not_supported` query. The canonical DOI/article URL is retained for citations. The GitHub data license does not automatically license all unrelated web content; this corpus relies on the article's own license and NIST's explicit information reuse terms.

Each paragraph's checksum is stored alongside it. The complete catalog, including metadata and URLs, is independently pinned in `llm/knowledge.py` as `a82b1d4b841a9008cfe8d2264e6355b167654069c8ed1fc1c2a065f331c2f711`. Changing both a passage and its local checksum does not bypass the catalog check. Adding or editing a source requires review, an updated catalog pin, tests and a new knowledge-base version; no web page is silently refreshed at runtime.

The provider treats retrieved content as untrusted input. It may select only approved claim/citation IDs. Python independently verifies every retrieved object against the pinned catalog and renders separate reviewed interpretation templates. Retrieved prose is never automatically promoted to a factual claim. A malformed citation, unreviewed source or changed passage causes abstention or deterministic fallback. Source links require HTTPS and a small explicit host allowlist, with no credentials or custom port.

The corpus supports only general limits of interpretation and data-quality context. It cannot identify a failure mechanism, establish causality, validate a sensor, provide well operating instructions or recommend physical action. It is deliberately too small for general petroleum-engineering question answering.
